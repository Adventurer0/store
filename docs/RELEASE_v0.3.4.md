# ShopDock Local v0.3.4 · 发布说明

日期：2026-11-03。基于 v0.3.3 增量实现，保留 FastAPI + SQLite + 商家网页任务模型。

## 本版范围

v0.3.3 只完成了快手新建商品的内置提交。本版补齐用户验收清单中的其余核心缺口：本地质量预评分、抖音/微信内置提交、已关联商品更新、失败店铺重试、审核状态回查、平台错误码翻译，以及快手旧批量创建在接入检查中的状态。

**本版仍未使用真实商家账号验收。** 真实页面入口、类目属性、资质、图片审核、评分展示、回执和审核状态仍需实店扫码后核对。

## 本地质量预评分

新增 `app/quality_checker.py`（内置标准库图片尺寸解析，不引入第三方图片依赖）：

- 100 分制：类目与属性 20、必填完整性 20、主图 20、详情内容 15、标题与卖点 10、SKU/价格/库存 10、物流与服务 5。
- 只有 **≥95 分且无硬性阻断** 才允许提交。
- 硬性阻断：未选类目、必填项为空、主图不足、图片尺寸无法读取、快手主图缺少 3:4、标题超限、SKU 编码/价格无效、新建商品 SKU 库存不为零。
- 图片尺寸使用标准库解析 PNG/JPEG/WebP/GIF，不引入第三方图片依赖；只读取本地素材文件。
- 平台评分与本地评分分开保存和展示。快手新建仍要求平台评分 >90；抖音/微信等平台没有可读取评分时，以本地 ≥95 为准；平台一旦返回评分证据，仍校验 >90。

## 抖音 / 微信内置提交

新增 `app/generic_submission.py`：

- 未配置有效 `product_create` 回执工作流时，快手使用原有专用适配，其他平台使用通用内置提交。
- 通用适配只操作可见控件：校验必填/校验错误、唯一识别提交按钮、点击后等待新的成功提示，并从页面文本或 URL 读取商品 ID；读不到就进入“结果待核对”。
- 支持新建和更新两种模式；更新必须已有平台商品 ID，回执 ID 必须与目标一致，绝不生成第二个商品。
- 通用提交不读取 SKU ID，返回空映射；后续可在商品中心手动补齐。快手新建仍从只读详情页回读 SKU ID。
- 已配置有效自定义工作流的店铺继续沿用原工作流，不被内置适配覆盖。

## 更新已关联商品

- `publish_drafts` 增加 `mode`（create/update），增量迁移，不删旧数据。
- 新建批次可选择“更新已关联商品”；创建时逐店校验平台商品 ID，缺失即阻断。
- 更新提交只更新 listing 状态、SKU 映射和回执，不会插入新商品。
- 快手更新使用已知编辑页；其他平台更新需要配置 `commerce_browser.edit_url`（包含 `{external_id}` 的 HTTPS 模板），未配置时失败即停。

## 失败重试、审核回查、错误码

- `POST /api/publish-groups/{id}/retry-failed`：只对 `needs_input` 目标重新入队；已提交、已成功、待核对目标不会自动重发。界面增加“重试失败店铺”。
- 新增 `workbench_audit` 只读任务和 `POST /api/publish-groups/{id}/audit`：读取已提交商品页面，归类审核中/通过/驳回/下架/未知；回查失败只更新审核字段，不改发布状态。快手使用已知详情页；其他平台需配置 `commerce_browser.audit_url`。
- 新增 `app/platform_feedback.py`：保留平台原始错误码，将常见资质、品牌授权、类目、图片、价格库存、验证码、权限、登录、限流问题翻译成本地提示；未知错误不会改写成成功。`publish_targets` 增加 `error_code`、`audit_status`、`audit_message`、`audit_code`、`audit_checked`。

## 接入检查

- 快手无创建工作时显示“内置可用”，不再显示“尚未适配”；说明旧批量创建仍需页面规则。
- 其他平台无创建规则时说明“统一发布可使用通用内置提交，需能识别新增商品入口”，不把它说成已适配。

## 兼容性

- 数据库仅追加列：`publish_drafts.mode`，`publish_targets.error_code/audit_status/audit_message/audit_code/audit_checked`；启动时自动迁移。
- 原有 `GET /api/publish-groups`、草稿、提交和快手专用适配接口保持兼容。
- 客户端新增字段：`mode`、`local_quality`、`local_quality_passed`、`platform_quality_required`、`platform_quality_ok`、`audit_*`、`error_code`；旧字段保留。

- 真实 Chrome：快手内置提交、通用抖音新建/微信更新、Kuaishou 更新、审核状态读取、歧义按钮拦截、超时分类。

## 未验收范围

真实抖音/微信/Kuaishou 商家账号、真实新增商品入口、类目属性资质、图片审核、平台评分、提交回执与审核状态；通用内置提交基于本地模拟 HTML，真实 DOM 变化时会阻断或进入待核对。更新与审核回查对非快手平台需要显式 `edit_url` / `audit_url`。
