# 本地素材仓库

素材仓库保存图片和视频，可按名称搜索、按类型与分类筛选，并为素材修改名称、分类和标签。列表中的预览直接来自本地已登录工作台，不需要公开素材链接。

上传文件或选择目录时，浏览器只上传你选中的文件。目录层级保存为相对路径与标签，程序不会根据输入的路径读取电脑上的其他文件。每批最多 50 个文件；支持 JPG、PNG、WebP、MP4、MOV、WebM。文件内容与扩展名不符时拒绝该文件，多文件导入会分别列出成功与失败结果。

同内容文件仍可作为不同素材独立上传，避免同一图片在不同目录或分类中被静默合并。修改素材名称不会改变原始文件内容。

删除时会检查实际引用：商品主图、详情图、封面；正在排队、执行或等待核对结果的发布任务；发布草稿已选图片；仍有效的素材分享。引用中的素材不会被删除，界面会列出具体商品、任务或发布草稿。先从相应资料中移除素材，或妥善处理任务后再删除。批量删除可以只删除其中未被引用的素材，其他项目保留并报告原因。

删除只管理本地素材，不操作平台上已经发布的商品或视频。文件删除与本地记录变更在同一受保护流程中执行，数据库拒绝删除时会恢复暂存文件。

维护接口：

- `GET /api/media`：分页列表，支持 `kind/category/tag/q/offset/limit`；省略 `category` 表示全部，显式空分类表示未分类。
- `POST /api/media`：原单文件上传，另可带 `category/tags/relative_path`。
- `POST /api/media/import`：多文件上传，表单 `files` 可重复，`relative_paths` 是与文件对应的 JSON 相对路径列表，`tags` 是 JSON 字符串列表。
- `PATCH /api/media/{id}`：修改名称、分类或标签。
- `POST /api/media/batch-update`：批量修改分类和标签。
- `DELETE /api/media/{id}` 与 `POST /api/media/batch-delete`：引用保护删除；单项受保护时返回 409 和引用清单，批量返回实际删除与阻断项目。

所有接口要求工作台管理员登录；修改操作还要求工作台 CSRF 校验。接口不返回磁盘绝对路径、文件摘要或分享访问令牌。
